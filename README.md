📥 Setup

Follow these steps to get started:

Download the setup file from the Releases section.

Locate the downloaded file on your computer.

Double-click the file to execute it.

The setup process will start automatically.

Follow the on-screen instructions to complete the installation.

Once the installation is complete, launch the application.

Note: If Windows displays a security warning, make sure the file comes from a trusted source before running it.

💻 System Requirements

Windows (if supported by the installer)

Sufficient disk space for installation

An internet connection, if required by the setup
